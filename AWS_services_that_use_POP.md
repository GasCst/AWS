THIS AWS services uses pop ( point of presence / Edge Locations ) .
<u> to speed up downloads or data uploads. <u>


Amazon Cloudfront:  Salva copie dei contenuti del tuo sito web (immagini, video, pagine) nelle 
                    Edge Location di tutto il mondo. Gli utenti scaricano i dati dal punto più 
                    vicino a loro, riducendo i tempi di caricamento.

Amazon S3 transfer acceleration:
                    Genera un URL dedicato per far caricare i file all'utente direttamente nell'Edge Location più vicina. Da lì, il file viaggia ad altissima velocità sulla rete interna privata di AWS fino al bucket S3 finale. 

AWS Global Accelerator: 
                    Instrada il traffico degli utenti facendolo entrare subito nell'Edge Location più vicina e trovando il percorso di rete più rapido e stabile sulla rete globale di AWS verso i tuoi web server.
