AWS GovCloud (US):
    una versione speciale del cloud AWS progettata per organizzazioni statunitensi che devono gestire dati sensibili e rispettare requisiti di sicurezza molto rigorosi.

GovCloud, sono Region AWS isolate logicamente dalle normali Region commerciali, con controlli di accesso e requisiti di sicurezza specifici.

AWS normale                            |    AWS GovCloud
Siti web, app, database, aziende.      |    Dati sensibili e workload regolamentati USA
